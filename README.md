# PrintQC Qwen3-VL LoRA

Experimental paired-image 3D-print under-extrusion classification with Qwen3-VL and a LoRA adapter.

This v0.1.0 repository is being prepared for a GitHub-only release. The official Qwen base model will be downloaded from Hugging Face, and the trained adapter will be downloaded from this repository's versioned GitHub Release.

Status: private release preparation.
